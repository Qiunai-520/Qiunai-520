🔬 Things I Like to Explore

我喜欢研究一些看起来“有点奇怪”的问题。

例如：

- 为什么这个程序运行不了？
- Linux 到底发生了什么？
- 一个网站是怎么从代码变成网页的？
- DNS 到底是怎么工作的？
- Git 为什么会出现奇怪的冲突？
- Docker 容器里面到底发生了什么？
- pnpm 为什么要使用软链接？
- Android 为什么不能像普通 Linux 一样操作文件？
- Cloudflare 是怎么把网站部署到全球的？

很多时候，一个问题真正有意思的地方并不是最终答案，而是：

为什么会出现这个问题。

💡 My Development Philosophy

01 — Build First

我更喜欢：

«先做出来，再不断改进。»

一个可以运行的项目永远比一个停留在脑海里的完美想法更有价值。

---

02 — Learn By Doing

我不太喜欢单纯背诵 API。

相比：

看教程 → 记知识 → 做练习

我更喜欢：

想做东西
   ↓
遇到问题
   ↓
搜索资料
   ↓
理解原理
   ↓
解决问题
   ↓
记录经验

这样学到的东西通常会更加深刻。

---

03 — Open Source

我认为开源不仅仅意味着公开代码。

它更像是一种：

分享、协作和共同创造。

一个人的想法可能很有限，但当代码被更多人看到、使用和改进之后，它就有机会变成一个真正有价值的东西。
